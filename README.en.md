## Overview

Main Features
- Corrects the "skew" of scanned PDFs
- Rearranges page order, inserts blank pages, and adds/inserts other files
- Splits and saves with delimiters (file names can be set in advance)

The most useful scenario is:
Adjusting the angle of scanned parts, adjusting the order as needed, automatically assigning part names, and outputting them all at once.

### Skew Correction
Fine adjustment in 0.01° increments, slider and step buttons (±1°/0.1°/0.01°), guide lines (horizontal/vertical), batch application to all pages, cropping. Supports lossless saving that preserves the original PDF structure, and the image quality does not decrease even if you redo it.

### Rearrangement
Page rearrangement, deletion, 90° rotation, blank page insertion, split saving with delimiters, A3→A4 split saving.

The suffixes added to file names when splitting can be entered as newline-separated text, and saved as presets.

### Screen Description (How to read the screenshots)
1) Tilt Correction: This shows the screen after opening a sheet music PDF and applying +1.00°. The page list is on the right.
2) Sorting: Page cards and operations related to splitting and saving.
3) Settings: Specify image quality, file name pattern, and save destination folder.
