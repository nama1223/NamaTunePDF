## 概要

主な機能
・スキャンしたPDFの「傾き」を直す
・ページ順の並べ替え、余白ページの挿入、別ファイルの追加挿入
・区切りを入れて分割保存(ファイル名を事前に設定可能)

一番役に立つ場面の想定は、
まとめてスキャンしたパート譜の角度を整えて、必要に応じて順序を調整し、パート名を自動付与して一気に出力する
です。

### 傾き補正
0.01°単位の微調整、スライダーと段階ボタン（±1°／0.1°／0.01°）、補助線（水平・垂直）、全ページへの一括適用、クロップ。元のPDF構造を保つ無劣化保存に対応し、やり直しても画質が落ちません。

### 並べ替え
ページの並べ替え・削除・90°回転・白紙挿入、区切りによる分割保存、A3→A4分割保存。

分割保存する時のファイル名に追加する文字はテキストによる改行区切りで指定でき、プリセットとして保存しておくこともできます。

### 画面説明（スクリーンショットの見方）
1) 傾き補正: 楽譜PDFを開いて+1.00°を適用したところ。右にページ一覧。
2) 並べ替え: ページカードと、分割・保存まわりの操作。
3) 設定: 画質やファイル名パターン、保存先フォルダの指定。
